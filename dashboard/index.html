Token Launch Radar

Protocols that record no token yet, ranked by what a launch would be worth.

How the ranking works

Each protocol's implied value is TVL times its category's market-cap-to-TVL ratio, where the ratio is the median of the protocols in that category that already have a token. The result is adjusted by the protocol's 7-day TVL change (clamped to -20% to +50%) and by how long it has run with no token (up to 3 years). No protocol name is special-cased: the same formula scores every row. Implied values are this entry's own claim, not a prediction that a token will be issued or what it will be worth. A protocol is shown as one that records no token in the snapshot, never as one that has none.
