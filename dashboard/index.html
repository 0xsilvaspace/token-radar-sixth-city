How the ranking works

Each protocol's implied value starts from its TVL with diminishing returns, so the board is not just TVL order: size is TVL to the power 0.9. That size is priced by its category's market-cap-to-TVL ratio, the median of the protocols in that category that already have a token (categories with fewer than 3 fall back to the global median, 0.21). Then four multipliers from the snapshot's own figures: the protocol's 7-day TVL change (clamped to -20% to +50%, weight 0.75), its category's momentum, the median 7-day change of that category's token protocols (clamped to -15% to +30%, weight 0.5), how long it has run with no token (log-scaled, 0.70 to 1.00 over 4 years), and how many chains it runs on (up to 1.15 for six or more). No protocol name is special-cased: the same formula scores every row, and every detail view shows the factor-by-factor working. Implied values are this entry's own claim, not a prediction that a token will be issued or what it will be worth. A protocol is shown as one that records no token in the snapshot, never as one that has none.
